# Phase 14 — Debt & Loan Manager

Work-in-progress milestone notes for the private debt/loan ledger.

- Debt records are never created automatically from SMS or transactions.
- Counterparty names and private notes are encrypted before Isar persistence.
- Confirmed transactions may be linked only after an explicit user selection and confirmation.
- Manual ledger entries never create or edit bank transactions.
- Due reminders are optional, local, and use generic notification text without names, amounts, accounts, or balances.
- Backup/delete-all integration and release documentation are completed before this milestone leaves draft status.
